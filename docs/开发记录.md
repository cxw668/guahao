医疗管理接口：

```
- 科室

- GET /medical/departments （分页查询）
- GET /medical/departments/{deptId}
- POST /medical/departments
- PATCH /medical/departments/{deptId}
- DELETE /medical/departments/{deptId}
- 医生

- GET /medical/doctors （分页查询）
- GET /medical/doctors/{doctorId}
- POST /medical/doctors
- PATCH /medical/doctors/{doctorId}
- DELETE /medical/doctors/{doctorId}
- 排班

- GET /medical/schedules （分页查询）
- GET /medical/schedules/{scheduleId}
- POST /medical/schedules
- PATCH /medical/schedules/{scheduleId}
- DELETE /medical/schedules/{scheduleId}
- 就诊人（删除为软删： status=1 ）

- GET /medical/patient-visitors （分页查询）
- GET /medical/patient-visitors/{visitorId}
- POST /medical/patient-visitors
- PATCH /medical/patient-visitors/{visitorId}
- DELETE /medical/patient-visitors/{visitorId}
- 预约

- GET /medical/appointments （分页查询）
- GET /medical/appointments/{appointmentId}
- POST /medical/appointments （自动生成 appointmentNo=APT+Seq.getId() ，默认 status=0 、 payStatus=0 ）
- PATCH /medical/appointments/{appointmentId} （通用更新）
- PATCH /medical/appointments/{appointmentId}/cancellation （取消：写 cancelReason ）
- PATCH /medical/appointments/{appointmentId}/payment （支付：写 payWay ，并置 payStatus=1 、 status=1 ）
- PATCH /medical/appointments/{appointmentId}/check-in
- PATCH /medical/appointments/{appointmentId}/completion
```
